📱 [Full Android] Comment connaître l'adresse IP du téléphone qui fait le partage ? ▼
Lorsque vous activez le point d'accès sur Android (via le bouton « 📡 Étendre l'essaim » ou les paramètres Wi-Fi du téléphone), Android lui attribue quasiment toujours l'adresse IP 192.168.43.1.
C'est cette adresse que les autres téléphones doivent renseigner dans Pairs seed : 192.168.43.1:7001.
🔒 [Full Android] Comment ajouter un téléphone à la Whitelist sans PC ? ▼
Dans l'application SwarmGlu sur le téléphone Leader, allez dans l'onglet Tableau de bord. En bas de l'écran, sous la section « Whitelist locale — ajouter un nœud », tapez l'identifiant du nouveau téléphone (ex. tel-eleve-5) et cliquez sur Ajouter. Le nœud est immédiatement autorisé et scellé dans le journal !
📡 [Wi-Fi Routeur] Les appareils ne se voient pas entre eux ▼
1. Isolation Wi-Fi (AP Isolation) : Dans les paramètres de votre routeur Wi-Fi autonome, assurez-vous que l'option « Isolation des clients » (*Client Isolation*) est désactivée, sinon le routeur empêche les appareils Wi-Fi de communiquer entre eux.
2. Pare-feu sur PC : Si un PC est présent, ouvrez le port TCP 7001 : sudo ufw allow 7001/tcp.
🔋 [Android] La tablette se déconnecte lorsque l'écran s'éteint ▼
Sur Android, le mode « Doze » coupe le réseau en veille prolongée.
Allez dans Paramètres ▸ Applications ▸ SwarmGlu ▸ Batterie et sélectionnez « Non restreinte » (*Unrestricted*). Le service d'arrière-plan maintiendra alors le nœud éveillé.
